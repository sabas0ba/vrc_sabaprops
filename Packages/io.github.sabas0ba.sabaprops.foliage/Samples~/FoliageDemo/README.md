# Foliage Demo

Package Manager から Sample を Import した後、`FoliageDemo.unity` を開いてください。

シーンには次の生成結果が含まれます。

- Grass / Small Flower / Dandelion の通常 Species
- 投影ガイドスプラインに沿う English Ivy preset
- 密度を高くして赤紫の秋色を混ぜた Boston Ivy preset
- 分岐する地下茎 Graph を共有するドクダミ型の地上茎

Surface Vine または Rhizome Patch を選ぶと、ガイド点、被覆率、分岐、葉形、葉密度、
パレット、Mesh 予算を確認できます。`Build / Rebuild` は指定した Collider へ経路を
再投影し、永続 Mesh を `Assets/SabaProps/Foliage/Generated/SurfaceGrowth` 以下へ更新します。
