# Changelog

このパッケージの変更点をまとめています。
フォーマットは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) に、
バージョニングは [Semantic Versioning](https://semver.org/lang/ja/) に従います。

## [0.1.0] - 未リリース

実クライアントでの挙動を確認するための初期版です。既定値は検証結果に応じて変更します。

### Fixed

- デバッグ形状の更新を20 Hzに制限し、円周計算の三角関数呼び出しを除去。操作ボタンの文字更新も変更時だけに制限

- 動作型マネキンのLegacy AnimationをWorld対応のAnimatorとControllerへ変更
- 検証シーンのGrab対象がプレイヤーのみであることを明記

### Added

- 検証シーンにGizmo・HUD・接触と引っ張りの独立切替ボタンを追加

- Grab入力の受信回数・開始結果と、実際の移動量をHUDに表示

- VR手足から相手の四肢への深い接触補正と、四肢専用の許容幅
- 相手の許可に基づく手・前腕のGrabと水平追従。保持状態の同期、速度・加速度制限、解除操作、有効期限、壁際の体幅判定
- 引っ張りの許可・解除ボタン、着席時の停止を伝えるStation補助コンポーネントと接続メニュー

- デバッグ線の遮蔽物越しの表示、対象外の腕・脚の灰色表示と切替、HUD の VR 判定と有効な判定点数
- 標準体型と一致するマネキンの外観、往復移動・旋回の動作型、1 m / 10 cm の床格子と検証項目のラベル

- `Body Contact System`: 他のプレイヤーの頭・体幹・四肢へ自分の体が侵入した分だけ、自分の位置を戻す Udon コンポーネント
  - 相手の形状は頭の球と、体幹・上腕・前腕・大腿・下腿のカプセルの計 10 部位
  - 自分側は頭・胸・腰・両手・両足の 7 点。Desktop では頭と体幹の 3 点だけを判定
  - 手足が相手の頭や体幹へ侵入した場合は手足の持ち主が退き、相手は動かない
  - 体幹同士は動いている側が退く。双方が静止していれば半分ずつ
  - 浅い侵入は許容し、超過分だけを戻す
  - 重なった状態で始まった相手と、接触が一定時間続いた相手は、離れるまで通り抜けを許可
  - 同期変数とネットワークイベントを持たない
- 標準体型の固定ダミー。ネットワークの遅延なしで応答を確認できる
- `Body Contact Debug View`: 形状・接触・分離ベクトルを World 内に線で描画し、侵入量と押し戻しの反転回数を表示
- System とダミーを配置する GameObject メニュー
- 床・壁・Spawn と 5 体のマネキン、引っ張り操作ボタン、Station を含む検証用シーンの生成メニュー

### 既知の制限

- 手足の貫通を止めるのは VR のみ。Desktop の手足は判定しない
- 真上と真下からの接触は解消しない。動かせるのが水平方向だけのため
- 肘と膝は自分側の判定点に含まない
- World の Station には接続メニューで補助コンポーネントを取り付ける必要がある。動的に生成する Station は個別に接続する
