# SabaProps Body Contact

プレイヤー同士の体の貫通を抑える Udon コンポーネントです。相手の体を頭・体幹・四肢の部位ごとに判定し、
自分の体が侵入した分だけ自分の位置を戻します。

- 歩いて相手の体を通り抜けられなくなります
- VR では、相手の頭や体幹へ手を押し込むと自分が後ろへ下がり、手が表面に留まります
- 他人を押して動かすことはできません
- 浅い接触は許容するため、撫でる・握手するといった動作では反応しません
- 同期変数とネットワークイベントを持ちません

0.1.0 は実クライアントでの挙動を確認するための初期版です。既定値は [検証手順](#検証手順) の結果に応じて
変更します。方式と判定規則の根拠は [設計](Documentation~/design.md) にあります。

---

## 導入

VCC でこのパッケージを追加すると、依存する VRChat Worlds SDK も一緒に解決されます。

## 使い方

### 検証用シーン

`Tools > SabaProps > Body Contact > Create Sample Scene` で、床・壁・Spawn・Body Contact System と
5 体のマネキンを含むシーンを生成します。保存先は `Assets/SabaProps/BodyContact/Samples/BodyContactDemo.unity`
です。そのまま VRChat SDK の Build & Test で起動できます。

| ダミー | 位置 | 用途 |
| --- | --- | --- |
| `Dummy Open` | 正面 | 歩いて入る、手を押し込む、の基本動作 |
| `Dummy Wall` | 右。手前に壁 | 壁とダミーの間に立ち、押し戻しが壁で止まることの確認 |
| `Dummy Small` | 左。0.6 倍 | 寸法が体格に比例することの確認 |
| `Dummy Moving` | 奥の左 | 左右 ±0.8 m、8 秒周期の往復移動に対する接触 |
| `Dummy Turning` | 奥の右 | 左右 ±60 度、8 秒周期の旋回に対する接触 |

マネキンの外観は判定と同じ標準体型から生成します。金色が頭・体幹、灰色が押し戻し対象外の腕・脚です。外観に Collider は付けません。床は 1 m の市松模様と主格子、10 cm の補助格子で距離を読み取れます。

動作型は全身の移動・回転を行う Animation です。関節ごとの歩行や手振りではありません。判定は毎フレーム同じ Transform を参照するため、外観と一緒に移動します。アニメーションの位相はクライアントごとで、ネットワーク同期の検証には使いません。

外観は生成時の `Dummy Eye Height` と `Radius Scale` に合わせます。これらを変更した場合は外観も生成し直してください。均等スケールでの拡大・縮小と位置・回転の変更は、そのまま外観と判定へ反映されます。
生成し直すと同名のシーンを上書きします。

### 既存のシーンへ配置

1. `GameObject > SabaProps > Body Contact System` を実行します。`Body Contact` がシーンのルートの原点に作成されます
2. 動作を 1 人で確認する場合は `GameObject > SabaProps > Body Contact Dummy` で固定ダミーを追加し、位置を調整します
3. Build & Test で確認します

`Body Contact` の子には、線を描画する `Debug Lines` と数値を表示する `Debug HUD` が含まれます。
`Debug Lines` は頂点をワールド座標で持つため、`Body Contact` を移動・回転・拡大しないでください。

ワールドを公開する際は、`Body Contact Debug View` の `Visible` をオフにするか、`Debug Lines` と
`Debug HUD` を削除します。

### Station との併用

Station に座っているプレイヤーを `TeleportTo` で動かすと、意図しない移動や降車が起きる可能性があります。
Station の `OnStationEntered` と `OnStationExited` から、ローカルプレイヤーの場合に `_Suspend` と
`_Resume` を呼んでください。

### 外部から呼べるイベント

| 対象 | イベント | 内容 |
| --- | --- | --- |
| `Body Contact System` | `_Suspend` | 判定と移動を停止します |
| `Body Contact System` | `_Resume` | 再開します。重なっている相手は、離れるまで通り抜けを許可します |
| `Body Contact System` | `_ToggleEnabled` | `Contact Enabled` を切り替えます。プレイヤーごとの無効化設定に使います |
| `Body Contact Debug View` | `_Show` / `_Hide` / `_ToggleVisible` | デバッグ表示を切り替えます |
| `Body Contact Debug View` | `_ToggleInactiveLimbs` | 押し戻し対象外の腕・脚の線を切り替えます |

## パラメータ

`Body Contact System`

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| Contact Enabled | オン | オフにすると判定も移動も行いません |
| Limb Probes In VR | オン | VR で手と足の侵入も判定します |
| Move Mode | 0 | 0 は `TeleportTo`、1 は `SetVelocity`。1 は比較検証用です |
| Radius Scale | 1 | 部位とプローブの半径に掛ける倍率 |
| Tolerance | 0.03 m | 許容する侵入量。超えた分だけ押し戻します |
| Response Seconds | 0.03 秒 | 押し戻しの時定数。小さいほど硬くなります |
| Max Speed | 6 m/s | 押し戻しの最大速度。走る速度より大きくします |
| Pass Through Seconds | 2.5 秒 | 体幹同士の接触がこの時間続くと、離れるまで通り抜けを許可します。0 以下で無効 |
| Broad Phase Factor | 0.8 | 双方の目線の高さの合計にこの値を掛けた距離より遠い相手は判定しません |
| World Collision Mask | Player と PlayerLocal 以外 | 押し戻された先の壁を調べるレイヤー |
| Dummies | なし | 標準体型マネキンの位置・回転。動く Transform も指定できます |
| Dummy Eye Height | 1.6 m | ダミーの目線の高さ |

寸法はすべてアバターの目線の高さに比例します。

## デバッグ表示

Unity の Gizmos は VRChat クライアントでは表示されません。`Body Contact Debug View` は同じ内容を
World 内に線で描画します。Editor の Play と VRChat クライアントの両方で表示されます。

| 表示 | 意味 |
| --- | --- |
| 緑のカプセル | 判定が有効な相手の頭・体幹 |
| 黄のカプセル | 通り抜けを許可している相手の頭・体幹 |
| 灰色のカプセル | 相手の腕・脚。押し戻し対象外 |
| 水色の球 | 自分の判定点 |
| 赤の球と線 | 接触している判定点と、相手側の最近点 |
| 紫の線 | 分離ベクトル。10 倍に拡大して腰の高さに描画します |

アバターや壁に隠れた線は薄く透過表示します。`Show Inactive Limbs` をオフにすると、対象外の腕・脚を非表示にできます。線が表示されていても、すべてが押し戻し対象とは限りません。手足同士は判定対象外なので、握手だけでは浅い接触の許容値を評価できません。

範囲外の相手は描画しません。数値表示の項目は次のとおりです。

| 項目 | 意味 |
| --- | --- |
| VR | ローカルプレイヤーが VR と判定されているか |
| probes | ボーン位置が有効な判定点数 / 使用する判定点枠数。通常は VR で 7/7、Desktop で 3/3 |
| limbs | 有効な手足の判定点数 / 4。Desktop または手足判定無効時は 0/4 |
| bodies / in range / pass-through | 相手の総数、判定範囲内の数、通り抜けを許可している数 |
| contacts / depth | 接触している判定点の数と、最大の侵入量 |
| separation / speed | 分離ベクトルの長さと、実際に動かした速度 |
| reversals | 直近 1 秒間に押し戻しの向きが反転した回数。振動の指標です |
| blocked by world | 押し戻された先に壁があり、移動を取り消した状態 |

Editor では、`Body Contact` を選択するとダミーの形状が Gizmos でも表示されます。

デバッグ表示は線の頂点を毎フレーム書き込むため、表示中は負荷が増えます。非表示の間は計算しません。

## 検証手順

実クライアントでしか確認できない項目です。結果に応じて既定値を決めます。

### 1. 位置を動かす手段

検証用シーンを Build & Test で 1 クライアント起動します。

1. ダミーへ歩いて入り、通り抜けられないことを確認します
2. VR でダミーの体幹へ手を押し込み、視点が滑らかに後退することを確認します
3. `Move Mode` を 1 に変えて同じ操作を行い、視点の滑らかさと、落下アニメーションの誤発動の有無を比較します
4. `Dummy Wall` と壁の間に立ってダミーへ手を押し込み、壁を抜けないこと、`blocked by world` が表示されることを確認します

### 2. リモートプレイヤーとの接触

Build & Test を 2 クライアントで起動します。

1. 互いに歩いて近づき、通り抜けられないことを確認します
2. 接触したまま双方が静止し、`reversals` が 0 のまま体が揺れ続けないことを確認します
3. 片方が静止し、もう片方が歩いて入ります。静止している側がほとんど動かないことを確認します
4. VR で相手の体幹へ手を押し込み、相手が動かず、自分が後退することを確認します
5. 接触したまま 2.5 秒待ち、相手が黄色になって通り抜けられることを確認します

### 3. 接触を伴う動作

1. 相手の頭を撫でる、握手する動作で、体が押し戻されないことを確認します
2. 押し戻される場合は `Tolerance` を上げ、通り抜けが目立たない範囲の値を探します

## 既知の制限

- 手足の貫通を止めるのは VR のみです。VR では実際の手の位置を止められないため、体全体を動かして
  手を相手の表面に留めます。Desktop の手足はアニメーションで動くため判定しません
- 真上と真下からの接触は解消しません。動かせるのが水平方向だけのためです
- 肘と膝は自分側の判定点に含みません
- リモートプレイヤーの姿勢には遅延があります。双方のクライアントで見えている相対位置は一致しません
- Humanoid でないアバターは、標準体型で代替した頭と体幹だけを判定します
- 同時に扱う相手は、ダミーとリモートプレイヤーの合計で 16 までです
