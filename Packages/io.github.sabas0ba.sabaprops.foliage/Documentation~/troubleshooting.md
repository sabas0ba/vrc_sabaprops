# トラブルシューティング

## Generate しても 1 本も生えない

ほぼ確実に地面のコライダーが原因です。順に確認してください。

1. 地面に Collider があるか（Terrain → TerrainCollider、メッシュ地形 → MeshCollider）
2. `Ground Layers` にそのレイヤーが含まれているか
3. `Raycast Height` がフィールド原点から見て地面より十分高いか
4. `Raycast Distance` が地面まで届いているか
5. Species の `Slope Limits` が地形の傾斜を弾いていないか
6. `Altitude Limits` が範囲外になっていないか

どうしても切り分けられないときは `Require Ground Hit` を一時的に OFF にしてください。
エリア平面に生えるようになれば、原因はレイキャスト側だと確定します。

## 草が真っ黒／真っ白になる

- シーンにライトプローブが無いと、生成された Renderer は環境光しか受け取れません。
  Light Probe Group を置いてベイクしてください。
- ライトマップをベイクしても草には反映されません（意図的な仕様です）。

## 風が揺れない

- マテリアルの `Wind > Strength` が 0 になっていないか確認してください。
- 別のシェーダーに差し替えている場合、`UV0.y` に高さ比、`UV3` に根元座標が入っている必要があります。
  READMEの「メッシュのチャンネル規約」を参照してください。

## 個体差が出ない／全部同じ色に見える

個体差は要素の根元のワールド座標から導出されます。フィールドをきわめて狭い範囲に
高密度で置くと、ハッシュの入力が近くなり差が出にくくなります。
`Hue / Saturation / Brightness Variance` を上げるか、Species の `Scale Range` を広げてください。

## 遠くの草が消える／ちらつく

- `Distance Shrink` の `Shrink End` が近すぎます。値を大きくしてください。
- 逆に視界の端で草が突然現れる場合は、風の振幅がメッシュ境界を超えています。
  `Wind > Strength` を下げるか、`Chunk Size` を小さくしてください。

## Merged Chunks にしたらカリングが効かなくなった

Merged Chunks はチャンク単位でしかカリングできません。`Chunk Size` を小さく
（例: 8 m）すると粒度が上がりますが、その分ドローコールは増えます。

## VRChat にアップロードしたら草が消えた

- マテリアルの GPU Instancing が OFF になっていないか確認してください。
- 生成物を Batching Static にしていないか確認してください。静的バッチングは
  頂点をワールド空間へ焼き込むため、このシェーダーの風と縮退が壊れます。
  シェーダー側で `DisableBatching = True` を指定しているので通常は起きませんが、
  他のシェーダーに差し替えた場合は注意が必要です。

## アップグレード後に生成メッシュへの参照が切れた

生成物は `Assets/SabaProps/Foliage/Generated/` に置かれ、パッケージフォルダの外にあるため
VCC のアップグレードでは消えません。もし参照が切れた場合は、各 Field で
**Generate** を実行し直せば復旧します。
