# Changelog

## [0.1.0] - 未リリース

### Added

- VR・Desktop共通の頭・体幹同士の侵入補正。浅い侵入の許容、速度に応じた負担分担、壁判定、通り抜け状態
- Station着席時の停止を伝える補助コンポーネントと接続メニュー
- 外観付きマネキン5体、往復移動・旋回、格子床を含む検証シーン生成メニュー
- 遮蔽物越しのGizmo、数値HUDとローカル切替ボタン。形状更新は20 Hz
- オフラインの幾何検査、UnityでのUdonコンパイル・生成シーン・描画検査
- ClientSim上のUdon実行、HUD描画画素、Gizmoメッシュ、表示切替の検査。配布シーンとビルド済みワールドの追加検査にも対応

### Changed

- 機能範囲を頭・体幹同士の補正へ限定。Pullと同期状態、Grab入力、四肢による移動補正、関連UIを削除
- 動作型マネキンはWorld対応のAnimatorとControllerを使用

### 制限

- 水平位置のみを補正。完全な非貫通は保証しない
- 実機での視点の快適性と通信遅延下の調整は継続事項
- サンプルシーン自体の最終パッケージ同梱は未実装
