# Trees Demo

![Trees Demoの季節・樹種比較](images/seasonal-overview.png)

この画像はUnity 2022.3.22f1でPackageの生成結果を実際に描画したものです。

## Sampleを開く

Package Managerで`SabaProps Trees`を選び、`Samples > Trees Demo > Import`を実行します。

- `TreesDemo.unity`: 混交林、スギ・ヒノキの植林、ケヤキ街路樹
- `SeasonalTreesDemo.unity`: シラカバ、ソメイヨシノ春／夏、イチョウ夏／秋
- `ForestLoadDemo.unity`: 64 / 128 / 192本の描画比較

## Demoで確認する項目

1. 樹種ごとの樹冠、分枝、葉序
2. 同じ樹種の季節差
3. LOD0 / LOD1 / LOD2の輪郭と切替
4. Tree Fieldによる複数個体配置
5. 風による枝と葉の応答

各樹種の画像と主要設定は[要素別リファレンス](elements.md)を参照してください。
